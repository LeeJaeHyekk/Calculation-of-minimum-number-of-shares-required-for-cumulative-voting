# Calculation-of-minimum-number-of-shares-required-for-cumulative-voting

집중투표제 시 회사측 보유 주식으로 선임할 이사 수 계산기

## 프로젝트 소개

이 계산기는 **집중투표제(누적투표제)**에서 회사 측이 특정 수의 이사를 선임하기 위해 필요한 최소 주식 수를 계산해 주는 웹 애플리케이션입니다.

### 계산 공식

```
필요한 최소 주식 수 = floor((N × S) / (D + 1)) + 1

여기서:
- N: 확보하려는 이사 수
- S: 총 발행 주식 수
- D: 전체 이사 수
```

## 데이터 구조 (ERD)

이 애플리케이션의 데이터 구조는 다음과 같습니다. 입력 데이터와 출력 데이터를 명확히 구분하여 설계되었습니다.

### ERD 다이어그램

```mermaid
erDiagram
    CumulativeVotingInput {
        number targetDirectors "확보하려는 이사 수 (N)"
        number totalShares "총 발행 주식 수 (S)"
        number totalDirectors "전체 이사 수 (D)"
    }
    CumulativeVotingResult {
        number minShares "필요한 최소 주식 수"
    }
    CumulativeVotingInput ||--o{

    CumulativeVotingResult : "calculates"
```

### 데이터 구조 설명

#### 1. 입력 데이터 (CumulativeVotingInput)

사용자가 계산을 위해 입력하는 세 가지 값입니다:

| 필드명            | 데이터 타입 | 설명                   | 제약조건                         |
| ----------------- | ----------- | ---------------------- | -------------------------------- |
| `targetDirectors` | `number`    | 확보하려는 이사 수 (N) | 1 이상의 정수, 전체 이사 수 이하 |
| `totalShares`     | `number`    | 총 발행 주식 수 (S)    | 1 이상의 정수                    |
| `totalDirectors`  | `number`    | 전체 이사 수 (D)       | 1 이상의 정수                    |

#### 2. 출력 데이터 (CumulativeVotingResult)

계산 결과로 반환되는 값입니다:

| 필드명      | 데이터 타입 | 설명                |
| ----------- | ----------- | ------------------- |
| `minShares` | `number`    | 필요한 최소 주식 수 |

#### 3. 데이터 관계

- **CumulativeVotingInput** → **CumulativeVotingResult**: 1:1 관계
- 입력 데이터를 기반으로 계산 함수가 실행되어 결과를 생성합니다
- 모든 계산은 순수 함수로 구현되어 동일 입력에 대해 항상 동일한 출력을 보장합니다

### 데이터 흐름

```
사용자 입력 → 유효성 검증 → 계산 로직 → 결과 출력
    ↓           ↓           ↓           ↓
CumulativeVotingInput → 검증 함수 → calculateCumulativeVoting → CumulativeVotingResult
```

## 사용 방법

### 1. 웹사이트 접속

웹 브라우저(Chrome, Firefox, Safari 등)를 열고 계산기 웹사이트에 접속하세요.

- 배포된 사이트: [배포 URL] (배포 후)

### 2. 입력 값 준비

계산을 위해 다음 세 가지 정보를 준비하세요:

#### 📝 입력 값 설명

- **확보하려는 이사 수 (N)**: 회사 측이 선임하고 싶은 이사 수
  - 예: 3명의 이사를 확보하고 싶다면 N = 3
  - 반드시 1 이상의 정수여야 합니다

- **총 발행 주식 수 (S)**: 회사의 전체 발행 주식 수
  - 예: 회사의 총 주식이 10,000주라면 S = 10000
  - 반드시 1 이상의 정수여야 합니다

- **전체 이사 수 (D)**: 이사회 전체 이사 수
  - 예: 총 7명의 이사가 있는 경우 D = 7
  - 반드시 1 이상의 정수여야 합니다
  - N은 D보다 클 수 없습니다 (N ≤ D)

### 3. 값 입력하기

웹페이지에서 세 개의 입력 필드를 찾으세요:

1. **"확보하려는 이사 수 (N):"** 필드에 N 값을 입력
2. **"총 발행 주식 수 (S):"** 필드에 S 값을 입력
3. **"전체 이사 수 (D):"** 필드에 D 값을 입력

#### 💡 입력 팁

- 숫자만 입력 가능합니다 (문자, 특수기호는 자동으로 차단됩니다)
- 입력 필드를 클릭하면 기존 값(1)이 자동으로 지워집니다
- 잘못된 값(음수, 0, N > D)을 입력하면 계산 버튼이 비활성화됩니다

### 4. 계산 실행

모든 입력이 완료되면 **"계산"** 버튼을 클릭하세요.

#### ⚠️ 주의사항

- 모든 필드가 채워지지 않으면 계산 버튼이 회색으로 비활성화됩니다
- 입력 값이 유효하지 않으면 에러 메시지가 표시됩니다

### 5. 결과 확인

계산이 완료되면 결과 영역에 **"필요한 최소 주식 수: [숫자]"**가 파란색으로 강조되어 표시됩니다.

#### 📊 결과 해석

- 표시된 숫자가 회사 측이 확보해야 하는 최소 주식 수입니다
- 이 주식 수만큼 확보하면 N명의 이사를 선임할 수 있습니다
- 실제로는 약간 더 많은 주식을 확보하는 것이 안전할 수 있습니다

### 6. 재계산 또는 초기화

- 다른 값을 계산하려면 입력 필드를 수정하고 다시 "계산" 버튼을 클릭하세요
- 모든 입력을 초기화하려면 **"초기화"** 버튼을 클릭하세요

### 예시 계산

```
입력:
- 확보하려는 이사 수 (N): 3
- 총 발행 주식 수 (S): 10000
- 전체 이사 수 (D): 7

계산 과정:
필요한 최소 주식 수 = floor((3 × 10000) / (7 + 1)) + 1
                   = floor(30000 / 8) + 1
                   = floor(3750) + 1
                   = 3751

결과: 3751주
```
